# Batch order 2 — extractions, run continuous

The second continuous run, under the same rules the first proved. The owner's approval of this document approves the batch; his word interrupts anywhere.

## The rules of the run

Unchanged from `batch-extractions-1.md`, plus two lessons from the first run, now law here:

- Every landing's record close flips the earned README boxes in the same landing — the first run missed one and flipped it late.
- A landing commit adds its named files only, never a whole directory — the first run's `git add docs/plans` swept the next rung's plans in early.
- As before: trial first, plan from the templates, rehearsal green, dispatch without review; gates bracket every task; no hardwired seeds; demos read-only; any moved number, failed hash, unlisted difference, or design question the source cannot answer stops the batch and waits; the owner's read of the record is the acceptance.
